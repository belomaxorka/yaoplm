# Attribution

Data and services YAOPLM relies on (ADR-0007). This file is generated by
`scripts/build-data.py` from `data/attribution.json`; edit the JSON.

## Bundled data

`data/titles.json.gz` (format 1, built 2026-10-27) is derived from
the first two sources below.
`data/game-info.json.gz` (format 1, built 2026-10-27; META-3, ADR-0050) is
derived from the next two: 4718 serials with facts from the
developer DAT, 6085 with a Wikidata item (matched by
PlayStation ID: 42 items, by title: 2218; ambiguous titles:
117, unmatched items: 1088).

written to the user's device. YAOPLM does not redistribute them (ADR-0007,
ADR-0035).
