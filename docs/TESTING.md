# YAOPLM — тестирование

## Уровни

| Уровень | Что | Где |
|---|---|---|
| Unit | Парсеры и писатели форматов, правила имён, хеши, планировщик | `cargo test` в каждом крейте |
| Golden | Побайтное сравнение результата с эталоном: `ul.cfg`, CFG, ZSO, заголовки VMC | `crates/*/tests/golden/` |
| Property / fuzz | Round-trip CFG и ZSO; парсеры не падают на мусоре | `proptest`, `fuzz/` (cargo-fuzz, локально и по расписанию) |
| Integration | Импорт во временный каталог и в образ FAT32 (`fatfs`/`hadris-fat`); нарезка >4 ГиБ через «виртуальный» большой файл без реального места на диске | `crates/yaoplm-core/tests/` |
| API | Каждый `Request` через `dispatch` и через `yaoplm rpc` | `crates/yaoplm-api/tests/`, `apps/cli/tests/` |
| UI unit | Компоненты, транспорт, i18n (все ключи есть в `en` и `ru`) | vitest |
| UI e2e | Сценарии в браузере против `yaoplm-server` с фикстурной библиотекой | Playwright, `web/tests/e2e/` |
| Desktop e2e | Позже: `tauri-driver` (WebDriver) на Windows и Linux | — |
| Железо | Реальная PS2 и OPL, чек-листы из ROADMAP | пользователь |

## Фикстуры

- **Реальные игры в репозиторий не коммитим никогда.** Фикстуры генерирует код в `yaoplm-test-support`:
  - крошечный ISO9660 с `SYSTEM.CNF` (`BOOT2 = cdrom0:\SLUS_200.62;1`) и пустым ELF;
  - варианты без `BOOT2`, с другим регистром, с длинным ID;
  - BIN/CUE (сырые 2352-байтные секторы) из того же ISO;
  - ZSO из того же ISO;
  - мини-DAT в формате Logiqx;
  - образ FAT32 на несколько МБ;
  - `VirtualLargeFile`: поток на 4,5 ГиБ, генерируемый на лету, для тестов нарезки.
- Эталоны (golden) лежат в репозитории как маленькие бинарные файлы. В `.gitattributes` они помечены `binary`, чтобы CRLF в CFG не портился.

## Перекрёстные проверки

- **ZSO:** `ziso.py` из репозитория OPL сжимает и распаковывает наши файлы, и наоборот. Запускаем в CI через Python.
- **`USBA_crc32`:** тестовые векторы двух видов.
  1. Реальные пары «имя игры → CRC» из имён чанков `ul.XXXXXXXX.*` на флешке, подготовленной OPL Manager или USBUtil (пользователь присылает список файлов, сами игры не нужны).
  2. Значения от C-функции из `src/system.c` OPL, скомпилированной в тестовом харнессе. Тогда `cc` — только dev-зависимость.
- **`ul.cfg`:** сравнение с `ul.cfg`, созданным OPL Manager (присылает пользователь).
- **CFG:** round-trip реальных CFG из комьюнити-баз (Tom-Bruise, GDX-X) без изменений.

## Проверка интерфейса агентом

1. `yaoplm-server --root <фикстурная библиотека>` и/или Vite dev server, запуск через `.claude/launch.json` и превью в браузере.
2. Playwright e2e и скриншоты ключевых экранов в обеих темах, на `en` и `ru`, при ширине 1280 и 800.
3. Сценарии: открыть устройство → увидеть игры → добавить игру → план → подтвердить → прогресс → игра в списке → обложка.

## Тестовые данные вне репозитория

Каталог `D:\yaoplm-testdata\` (на D: больше места; не в git):
```
D:\yaoplm-testdata\
├─ iso\         # собственные дампы пользователя (не скачиваются агентом)
├─ homebrew\    # свободные homebrew-ELF/ISO для тестов
├─ opl\         # официальные сборки OPL с GitHub releases (1.1.0 и 1.2.0 beta), справочно
├─ images\      # образы FAT32/exFAT для интеграционных тестов
└─ out\         # результаты прогонов
```
Тесты, которым нужны реальные данные, помечены `#[ignore]` и запускаются только при заданной переменной `YAOPLM_TESTDATA=D:\yaoplm-testdata`.

**Агент не скачивает коммерческие образы игр.** Скачивать можно: официальные релизы OPL, открытые инструменты (`ziso.py`, hdl-dump и т.п. из исходников), homebrew, открытые базы данных.

## Что нужно от пользователя

1. PS2 с OPL 1.2.0 beta (последняя сборка). Желательно ещё OPL 1.1.0, на второй флешке или через выбор при запуске.
2. Флешки: одна в FAT32, одна в exFAT, от 8 ГБ.
3. Дампы **своих** дисков в `D:\yaoplm-testdata\iso\`:
   - CD-игра (синяя сторона диска);
   - DVD-игра до 4 ГиБ;
   - игра больше 4 ГиБ (DVD-9 или крупный DVD-5);
   - позже PS1-игра в BIN/CUE и, если есть, многодорожечная.
4. По возможности флешка, подготовленная OPL Manager: нужен список файлов и `ul.cfg` для эталонов.
5. Позже: сетевой адаптер для SMB и HDD для внутреннего диска (fat PS2).
