# Сведения об игре в CFG (META-3, шаг 2): чек-лист для консоли

PR: `m6/meta-3-cfg`. Что проверяем: страница сведений темы OPL показывает ключи, которые YAOPLM записал планом (`Title`, `Genre`, `Release`, `Developer`, `Publisher`, `Players`, по выбору `Description`), и переименование игры обновляет `Title` в CFG. Носитель: флешка FAT32 (серийник `3C76-1797`); сборки: OPL 1.2.0 beta (`latest`) и OPL 1.1.0; RiptOPL для слота `Players`.

Подготовка (на ПК, только планами, после подтверждения): игра с ID из встроенной таблицы (например `SLUS_200.62`, GTA III), `yaoplm cfg <root> SLUS_200.62 --write-info --yes` (или карточка игры, когда она появится в шаге 5); вторая игра с `Title=...` в CFG, переименованная через «Переименовать…».

| № | Что сделать на консоли | Ожидаемо | Факт |
|---|---|---|---|
| 1 | OPL 1.2.0 beta, встроенная тема, игра с записанными ключами → страница сведений (□) | Строки Title, Genre, Release, Developer, Description (если записано) показывают значения из CFG; Size — от OPL | |
| 2 | Та же игра, OPL 1.1.0 | То же, что в п. 1 | |
| 3 | `Release=10-23-2001` на экране | Печатается как есть, `10-23-2001` | |
| 4 | `Description` длиннее одной строки | Переносится в поле 574×80, обрезанный по концу предложения текст читается целиком | |
| 5 | RiptOPL, встроенная тема | `Title`, `Developer`, `Description` видны; слот `Players` при записанном `Players=players/N` пуст (текстур нет), без `Players` — картинка «missing» | |
| 6 | Игра, переименованная в YAOPLM (CFG имел `Title`) | На странице сведений новое название | |
| 7 | CFG с русским `Description` (записан по явному выбору), язык OPL English | Кириллица не отображается (нет глифов) | |
| 8 | То же, язык OPL Russian с `font_Russian.ttf` из языкового пака | Русский текст читается | |
| 9 | wOPL с файлом `.cfg` libconfig | YAOPLM ничего не переписывал, игра запускается как раньше | |
| 10 | Игра, добавленная с включённым переключателем «Сведения об игре в CFG» (шаг 3, PR `m6/meta-3-add`), без других действий | На странице сведений темы OPL её Title, Genre, Release, Developer | |

Результаты записываются сюда после серии на консоли (`docs/testing/README.md`).
