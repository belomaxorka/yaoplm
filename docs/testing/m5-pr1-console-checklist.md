# M5, PR 1 — чек-лист: проверка дампов, конвертации, импорт из архивов и CHD

Первый PR вехи M5 (ветка `m5/dumps-and-conversions`: GAME-4, GAME-5, META-2, IMP-1b). Проверяет владелец на своей PS2. Отмечайте пункты по мере прохождения; замечания — отдельными маленькими PR. Общие правила тестовых данных — в [TESTING.md](../TESTING.md).

Рассчитано на флешку E: (FAT32, серийный номер тома `7E1CD2C5`), OPL 1.2.0 beta и OPL 1.1.0 с карты FreeMcBoot. Загрузочный тестовый диск — wLaunchELF (`YAOP_000.01`), упакованный всеми способами из IMP-1b, так что весь путь «архив или CHD → флешка → запуск» проверяется без коммерческих образов. Каждая запись на E: идёт через план; подтверждайте только их.

## Подготовка

- [ ] 1. Запустить `pnpm tauri dev` из `apps/desktop` (сборки релиза для M5 ещё нет). «Настройки → Библиотека»: профиль `OPL 1.2.0 beta`, имена `ID.Название.iso`.
- [ ] 2. Тестовые файлы на D: (готовит агент; если папки нет — команды ниже):
  - `D:\yaoplm-testdata\out\m5-packed\`: `YAOP_000.01.wLaunchELF.zip`, `.7z`, `(DVD).chd`, `(CD).chd` (с аудиодорожкой), `.cue` с `(Track 1).bin` и `(Track 2).bin`. Команда: `cargo run -p yaoplm-test-support --example pack -- D:\yaoplm-testdata\out\YAOP_000.01.wLaunchELF.iso D:\yaoplm-testdata\out\m5-packed`;
  - `D:\yaoplm-testdata\out\YAOP_000.05.wLaunchELF 4300MiB.iso` (больше 4 ГиБ, загружается).
- [ ] 3. По желанию, для проверки по Redump: ваш собственный архив с игрой (zip или 7z с ISO внутри), скачанный раньше.
- [ ] 4. «Носители» → карточка E: → «Открыть библиотеку». Если на флешке уже есть `YAOP_000.01`, удалите эту игру (её ID нужен ниже).

## Проверка дампов (на ПК)

- [ ] 5. «Настройки → Проверка дампов (Redump)» → «Скачать с Redump» (нужен интернет). Ожидается: «Скачано, записей: …» (около 11 800) и строка «DAT Redump <дата>, записей: …». Кнопка «Проверить обновление» становится неактивной до даты через неделю.
- [ ] 6. Библиотека → «Проверить дампы» → «Все игры» → «Проверить». В журнале по строке на игру; у фикстур и wLaunchELF «неизвестен» с причиной «Нет в Redump» (это homebrew). На карточках в библиотеке появляется значок щита.
- [ ] 7. Ещё раз «Проверить дампы» → «Все игры»: проверка почти мгновенная, у строк «Хеши из кэша».
- [ ] 8. Если есть своя игра (п. 3): импортируйте её (п. 9), затем «Проверить дамп» в карточке игры. Ожидается «Подтверждён» и название Redump со ссылкой. «Плохой дамп» или «неизвестен» — пришлите название игры и регион.

## Импорт из архивов и CHD

- [ ] 9. «Добавить игры» → «Добавить файлы…»: в фильтре диалога видны `.chd`, `.zip`, `.7z`. Выбрать `m5-packed\YAOP_000.01.wLaunchELF.7z` → «Показать план». Ожидается: запись `CD/YAOP_000.01.wLaunchELF.iso` с пометкой «Читается прямо из архива, без распаковки на компьютер». «Записать на носитель».
- [ ] 10. Консоль, OPL 1.2.0 beta, USB: wLaunchELF в списке и запускается.
- [ ] 11. ПК: карточка игры → «Проверить дамп» → «Хеши»: запишите SHA-1. Затем «Удалить» → «Показать план удаления» → подтвердить.
- [ ] 12. Повторить пп. 9 и 11 по очереди для `(CD).chd`, `.zip`, `.cue` и `(DVD).chd`, удаляя игру после каждого. У каждого SHA-1 тот же, что в п. 11. У `(CD).chd` и `.cue` в плане предупреждение «Звуковые дорожки не переносятся…».
- [ ] 13. Включить «Перемещать, а не копировать» и добавить `.7z`: в плане заметка «Архив, из которого взята игра, не удаляется»; после записи `.7z` остаётся в папке.
- [ ] 14. Перетащить `.zip` из проводника в окно «Добавить игры»: появляется в списке источников, план строится.

## Конвертации

- [ ] 15. Карточка wLaunchELF (ISO) → «Конвертировать…» → ZSO → «Показать план». В плане «Сжать в CD/…zso» и удаление `.iso`, кнопка недоступна до отметки «Я понимаю, что файлы будут удалены». Подтвердить. Формат в карточке — ZSO, размер меньше.
- [ ] 16. Консоль, OPL 1.2.0 beta: wLaunchELF запускается из ZSO. OPL 1.1.0: игры нет в списке или она не запускается (1.1.0 не читает ZSO, это ожидаемо).
- [ ] 17. «Конвертировать…» → ul: на флешке `ul.XXXXXXXX.YAOP_000.01.00` и запись в `ul.cfg`, ZSO удалён. Консоль (1.2.0 и 1.1.0): запускается.
- [ ] 18. «Конвертировать…» → ISO: снова `CD/YAOP_000.01.wLaunchELF.iso`, частей ul и записи в `ul.cfg` нет. Консоль: запускается.
- [ ] 19. Добавить `YAOP_000.05.wLaunchELF 4300MiB.iso`: на FAT32 план режет его на 5 частей ul. Затем «Конвертировать…» → ZSO: в плане предупреждение «FAT32 вмещает файлы до 4 ГиБ…»; ZSO выходит маленьким (образ почти весь из нулей). Консоль, OPL 1.2.0 beta: запускается из ZSO.
- [ ] 20. «Сжимать в ZSO» на экране добавления, источник `.7z`: в плане «Сжать в …zso», игра сразу в ZSO. Консоль: запускается.
- [ ] 21. Библиотека → фильтр «ZSO» → «Конвертировать…» → ISO: в диалоге «Будут конвертированы: N из N», план на все показанные игры.
