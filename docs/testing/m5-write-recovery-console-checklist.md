# M5: запись и восстановление по журналу — проверка на консоли (IMP-5, IMP-8, GAME-2)

Что проверяем: после флешки, выдернутой посреди записи, восстановление оставляет носитель таким, каким его ждёт OPL. «Откатить» не оставляет следов недописанной игры, «Завершить» дописывает её, и в списке нет повторов (`games.bin` удалён и OPL собрал его заново). Удаление игры убирает её из списка. PR #46, подробности — ADR-0021 и TESTING.md, «Сбои и восстановление».

## Что нужно

- Тестовая флешка FAT32 (узнаём по серийному номеру тома).
- Две-три небольшие игры, например homebrew-ISO из `$YAOPLM_TESTDATA\out\`. Для п. 1 удобнее, чтобы вторая игра писалась несколько секунд: `YAOP_000.06.wLaunchELF 1000MiB.iso` (1 ГиБ).
- Любая сборка OPL (1.1.0 или 1.2.0 beta).

## Шаги

- [ ] 1. **Откат.** На ПК добавьте в YAOPLM две-три игры на флешку. Посреди записи второй игры выдерните флешку (политика удаления «Оптимальная производительность» делает сбой жёстче; «Быстрое удаление» по умолчанию тоже подходит). Вставьте её обратно: YAOPLM пишет «1 операция не завершена». Выберите «Откатить».
   - В YAOPLM первая игра на месте, от второй ничего не осталось.
   - **На консоли** в списке ровно первая игра, и она запускается.
- [ ] 2. **Докат.** То же, но в восстановлении выберите «Завершить».
   - **На консоли** обе игры в списке и запускаются, без повторов.
- [ ] 3. **Удаление.** Удалите игру в YAOPLM и подтвердите.
   - **На консоли** её нет в списке, остальные игры на месте.
