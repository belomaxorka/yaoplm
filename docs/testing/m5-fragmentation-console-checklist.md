# M5: проверка фрагментации на консоли (IMP-7b, LIB-4)

Что проверяем: YAOPLM считает куски файлов так же, как OPL. Игра сверх лимита в OPL не запускается, а YAOPLM заранее предупреждает об этом в библиотеке и после записи. Подробности — ADR-0037, research/06 §1.11.

## Что нужно

- Тестовая флешка FAT32 (подойдёт E:) и около 2,5 ГБ свободного места на ней.
- OPL 1.2.0 beta (последняя сборка). Если есть — OPL 1.1.0 для шага 4.
- Тестовые образы homebrew из `D:\yaoplm-testdata\out\`: `YAOP_000.01.wLaunchELF.iso` (530 КиБ) и `YAOP_000.06.wLaunchELF 1000MiB.iso` (1 ГиБ). Оба запускают wLaunchELF, коммерческих игр не нужно.
- Утилита для игры «кусками» (пишет на флешку только `--out` и свой временный `<out>.filler`, который сама же удаляет; запускаете её вы):

```
cargo run -p yaoplm-test-support --example make_fragmented -- --image <образ> --out <путь на флешке> --pieces <N>
```

Она печатает, на сколько кусков Windows в итоге разложила файл. YAOPLM должен показать то же число.

## Шаги

1. **Обычная запись.** Добавьте в YAOPLM `YAOP_000.01.wLaunchELF.iso` на флешку.
   - В итоге записи нет предупреждения о кусках.
   - В карточке игры (расширенный режим, «Сведения») — «Кусков на носителе: 1 (OPL загружает игру не больше чем из 64)».
   - В OPL 1.2 игра запускается (появляется wLaunchELF).
2. **Игра в 70 кусках.** Выполните:
   `cargo run -p yaoplm-test-support --example make_fragmented -- --image "D:\yaoplm-testdata\out\YAOP_000.06.wLaunchELF 1000MiB.iso" --out "E:\DVD\YAOP_000.06.Fragmented.iso" --pieces 70`
   - Утилита пишет «… in 70 pieces» (или близкое число больше 64).
   - В YAOPLM после обновления библиотеки у игры есть предупреждение «Игра лежит на носителе кусками (частей: 70)…», а фильтр «Только игры с предупреждениями» её показывает.
   - `yaoplm scan E:\` показывает в колонке `PIECES` то же число.
   - В OPL 1.2 игра **не запускается**: OPL пишет, что игра фрагментирована. Запишите точный текст сообщения.
3. **Ровно на границе.** Удалите игру из шага 2 через YAOPLM и повторите команду с `--pieces 64`.
   - Предупреждения нет, в карточке — «64 (…не больше чем из 64)».
   - В OPL 1.2 игра запускается.
4. **OPL 1.1.0** (если есть). В настройках YAOPLM выберите профиль «OPL 1.1.0». Удалите игру из шага 3 и повторите команду с `--pieces 2`.
   - YAOPLM предупреждает: «…OPL 1.1.0 запускает игру по USB, MX4SIO и iLink, только если каждый файл — один кусок…».
   - OPL 1.1.0 игру не запускает, OPL 1.2 — запускает.
5. **Убрать за собой.** Удалите тестовые игры через YAOPLM (с подтверждением) и верните профиль, если меняли.

## Что прислать

- Для каждого шага: «как ожидалось» или что было вместо этого.
- Текст сообщения OPL из шагов 2 и 4 (фото экрана тоже подойдёт).
- Вывод `yaoplm scan E:\` после шага 2.
