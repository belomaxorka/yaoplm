# M5: SD эмулятора карты памяти — распознавание и защита (PR 1 плана `emulator-sd`)

Что проверяем: SD эмулятора, на которой YAOPLM только создал папки OPL, работает в эмуляторе как прежде. YAOPLM распознаёт такую SD по файлам эмулятора, не ставит на неё загрузчик и не трогает `.sd2psx/` и `MemoryCards/` (ADR-0048). На консоли от этого PR зависит одно: папки OPL и служебная папка `.yaoplm/` в корне SD не мешают прошивке и OPL с MMCE.

## Что нужно

- PSXMemCard Gen2 с прошивкой sd2psXtd 1.4.0 в слоте 1.
- Тестовая microSD 8 ГБ (заводская, серийный номер тома `C0EE-DE33`), подготовленная так:
  1. YAOPLM распознал её как «SD эмулятора карты памяти»;
  2. на вопрос «Какой OPL с MMCE вы запускаете?» ответили «Форк OPL с MMCE, YAOPL или wOPL»;
  3. кнопкой «Создать папки OPL» созданы `CFG`, `THM`, `LNG`, `ART`, `VMC`, `CHT`, `APPS`, `CD`, `DVD` в корне;
  4. `.sd2psx/` и `MemoryCards/` совпадают с копией по `files.tsv` (`$YAOPLM_TESTDATA\backups\psxmemcard-gen2-sd-2026-10-26`).
- После проверки карта возвращается в заводское состояние из копии (README, «Как пройдёт проверка», п. 5).

## Шаги

- [ ] 1. **Карта монтируется.** Эмулятор включается без «FATAL ERROR / failed to mount the card», в меню «Info» видна карта на 8 ГБ.
- [ ] 2. **Загрузочная карта на месте.** На канале 1 (имя на экране — «FMCB 1.966») консоль загружает FreeMcBoot 1.966, меню такое же, как до подготовки. Папки OPL в корне SD на это не влияют: прошивка читает только `.sd2psx/` и `MemoryCards/`.
- [ ] 3. **Настройки эмулятора не изменились.** В меню эмулятора PS2 Autoboot — «Yes», размер новых карт — 64 МиБ: это заводской `settings.ini`, YAOPLM его не трогал. YAOPLM об этом размере только предупреждает.
- [ ] 4. **OPL с MMCE видит пустые папки.** В FreeMcBoot пункт «Open PS2 Loader (MMCE Beta2)» (v1.2.0-Beta-2216). В настройках OPL режим MMCE «Авто», сохранить (без этого MMCE выключен, research/19 §4). Страница MMCE открывается без ошибок, игр нет, `.yaoplm/` не виден как игра.
- [ ] 5. **YAOPLM после консоли.** Вставьте SD в картридер: YAOPLM по-прежнему показывает «SD эмулятора карты памяти», каналы и ответ на вопрос о версии. Если OPL сохранил настройки, они легли внутрь загрузочной карты (`BootCard-1.mcd`), а не на SD: в корне SD нового `conf_opl.cfg` нет.

Игры на SD для OPL с MMCE (запуск, правило фрагментов, `ul`) — в чек-листе PR 3 плана; загрузочные карты и карты по ID игры — `m5-psxmemcard-console-checklist.md`.
