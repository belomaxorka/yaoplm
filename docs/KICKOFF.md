Привет! Начинаем разработку YAOPLM (Yet Another OPL Manager) — кроссплатформенного менеджера игр PS2 для Open PS2 Loader.

1. Прочитай `CLAUDE.md`, затем `docs/SPEC.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`, `docs/DECISIONS.md` и `docs/TESTING.md`. Отчёты в `docs/research/` открывай по мере надобности. Для форматов главный справочник — `02-opl-formats.md`.
2. Начинаем с вехи **M0 — Фундамент** из ROADMAP.
   - Установи недостающее: rustup (stable, MSVC), pnpm через corepack, Tauri CLI. Проверь, что в VS Build Tools 2026 есть C++-нагрузка.
   - Создай Cargo workspace, `web/`, `apps/cli`, `apps/server` и `apps/desktop` по ARCHITECTURE.md.
   - Настрой CI на трёх ОС, smoke-тест Playwright и `.claude/launch.json` для превью интерфейса.
3. Работай в ветке `m0/foundation`. Коммить маленькими шагами: Conventional Commits на английском. В конце открой PR в `belomaxorka/yaoplm` с описанием и проверь, что CI зелёный.
4. Интерфейс проверяй сам: запускай server mode или Vite через превью и смотри в браузере, делай скриншоты.
5. Окружение в твоём распоряжении: можешь ставить инструменты, компилировать, запускать, скачивать открытые инструменты и данные. Коммерческие образы игр не скачивай. Если для тестов нужны мои дампы или проверка на PS2 — скажи, что именно нужно.
6. Если по ходу примешь решение, которое меняет спецификацию, запиши ADR в `docs/DECISIONS.md` и скажи мне.

Общайся со мной на русском. Когда M0 будет готов, дай краткий отчёт и предложи план M1.
