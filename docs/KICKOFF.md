Привет! Продолжаем разработку YAOPLM. Веха M4 закрыта (PR #14, тег `v0.1.0`, пре-релиз опубликован с шестью пакетами). Есть:
- ядро: импорт ISO/ZSO/BIN/CUE с нарезкой `ul`, переименование, удаление, перенос CD↔DVD, журнал с откатом и докатом, задания с прогрессом и журналом шагов, встроенная база названий (`data/titles.json.gz`, ADR-0024), планы обложек с резервной копией (ADR-0025), CLI (`yaoplm add/rename/rm/mv/recover/art/about`);
- `yaoplm-net`: HTTP-клиент (User-Agent, ≤1 запрос/с на источник, ETag, back-off), кэш `art-cache/` с манифестом `cache.sqlite`, источники xlenore и libretro-thumbnails с режимом локального зеркала, перекодирование в PNG размера профиля;
- интерфейс (один SPA для Tauri и `yaoplm-server`): обложки в сетке, списке и карточке (asset-протокол на десктопе, `/media/art` на сервере), диалог «Скачать обложки» с охватом и журналом по играм, замена из файла, буфера обмена и drag-and-drop, удаление через план, настройки источников и кэша, экран «О программе» с атрибуцией;
- e2e Playwright на фикстурной библиотеке с зеркалами (`make_library`), скриншоты в ветке `pr-assets/m4`;
- релизная сборка `release-desktop.yml` по тегу `v*` (Windows NSIS/MSI, Linux AppImage/deb/rpm, macOS universal dmg ad-hoc), проверена на трёх платформах, публикует черновик пре-релиза; updater не подключён (ключа нет); повторный запуск по `workflow_dispatch` на `main` кладёт ассеты в релиз тега из версии Cargo.

Проверка M4 на консоли ещё впереди: пошаговый список — `docs/testing/m4-console-checklist.md`. Замечания по проверке M3 и M4 в GUI и на консоли могут прийти по ходу вехи: их исправляем отдельными маленькими PR, не смешивая с ветками M5.
