# План: эмулятор карты памяти (sd2psx / sd2psXtd) и его microSD в YAOPLM

Источник — сессия 2026-10-26 с владельцем продукта. Прошивка PSXMemCard Gen2 обновлена до sd2psXtd 1.4.0, заводская microSD описана и сохранена, раскладка перенесена на Kingston 128 ГБ.

Факты лежат в трёх местах:
- research/19 — устройство владельца, его SD, загрузочные карты, переезд, что нужно YAOPLM;
- research/07 §2.7 — раскладка SD у sd2psx, MMCE, карты по ID игры;
- research/06 §1.4 — таблица разделов.

Требования SPEC: DEV-2 (распознавание носителя), DEV-3 (форматирование, здесь защита от него), DEV-4 (мастер подготовки), LIB-1 (профиль), LDR-1/LDR-3 (форк с MMCE), LDR-5 (OPL внутри загрузочной карты), VMC-2 (сейвы). Нужен новый ADR: следующий номер — **ADR-0048**.

## Что решил владелец (2026-10-26)

- **Два способа работы с одним устройством:**
  - microSD эмулятора вставлена в картридер — работа с файлами;
  - эмулятор подключён к ПК по USB-C.

  Программа поддерживает оба.
- **SD эмулятора — отдельный вид носителя.** Программа его распознаёт и никогда не портит:
  - не пишет в `.sd2psx/` и `MemoryCards/` иначе как через явные функции работы с картами;
  - не ставит туда загрузчик;
  - не даёт его форматировать.

  Потерять загрузочные карты с FreeMcBoot дорого.
- **OPL обновляется внутри загрузочной карты** (LDR-5), а сейвы редактируются в образах карт (VMC-2).
- **Обновлять прошивку эмулятора из YAOPLM не нужно**: хватает перетаскивания UF2 по README sd2psXtd.
- **Новая карта без исходной** собирается из образов SD Builder (research/19 §5). Своя заводская раскладка восстанавливается из копии.

## Что умеет USB (важно: файлов по USB нет)

| Прошивка | Что видно по USB | Что можно |
|---|---|---|
| до 1.4.0 | ничего (только питание) | — |
| **1.4.0** (у владельца) | последовательный порт (USB CDC) и интерфейс сброса, VID `2E8A` PID `000A`. Появляется только после того, как SD смонтирована | `help`, `reset bl`, `reset dev`, `channel up/down`, `set channel <n>`, `card up/down`, `set card <n> [channel <n>]`, `set game <id> [channel <n>]`, `set mode ps1/ps2`, `set variant retail/proto/conquest/arcade` |
| ветка `develop` (b3c9a54, не выпущена) | то же | ещё `version` (версия, коммит, ветка, вариант железа, режим, вариант PS2) и **только чтение** SD: `ls [путь]` (`D <имя>` / `F <размер> <имя>`, не больше 512 записей, затем `Total: N`), `stat <путь>` (`Dir:` / `File: … size N` / `Missing:`); пока PS2 работает с картой — `Busy: card operation in progress` (PR #106) |

- **Режима флешки (USB mass storage) нет** ни в sd2psXtd, ни в исходном sd2psx: включён только `pico_enable_stdio_usb`. Чтения и записи файлов по порту нет ни в одной ветке, запросов на это в трекере тоже нет.
- **Игры, загрузочные карты и сейвы — только через картридер.** По USB — управление и, с новой прошивкой, просмотр.
- **Если понадобится запись по USB**, это доработка прошивки upstream (GPL-3; PR туда принимают, #106 — от стороннего автора). Ограничение — USB full speed: порядка 1 МБ/с, так что 8-мегабайтная загрузочная карта займёт около 10 секунд, а игра на 4 ГиБ — больше часа. Писать во время работы консоли с картой нельзя. Это вне этого плана.
- **Порт узнаётся по ответу.** VID/PID `2E8A:000A` — стандартный для любой платы на RP2040 со stdio по USB, поэтому по ним одним эмулятор не отличить. Узнаём по ответу на `help` (строка `Serial Input Commands:` и команды sd2psx) и, где есть, `version` (`HW Variant`).
- **Протокол:**
  - DTR нужен (иначе pico-sdk молчит);
  - строка кончается CR, LF или CR LF;
  - прошивка повторяет набранные символы, в выводе есть ANSI-последовательности (`\x1b[D`), приглашение — `> `;
  - ответы — текст (`Set Card Index: %d`, `Invalid command`, `Invalid Game ID: …`).

  Стенограмма `help` с устройства владельца — в конце плана, для тестов.
- **Отличия `develop` от 1.4.0, кроме команд:** `develop` монтирует **GPT и SD без таблицы разделов** (PR #112), а 1.4.0 — только MBR, раздел 1. Советы доктора зависят от версии прошивки.

## Задачи (по PR, по порядку)

1. **ADR-0048** — эмулятор карты памяти: SD эмулятора как вид носителя, управление по USB, что запрещено, связь двух подключений одного устройства.
2. **PR 1 — распознавание и защита (DEV-2).**
   - Признаки SD эмулятора:
     - `.sd2psx/` (sd2psx/sd2psXtd);
     - `MemoryCards/<PS2|PS1|COH|SC2|PROT>/…`;
     - `mcp2.bin` и `os/` (MemCard PRO 2, research/07 §2.7).
   - Новый вид носителя рядом с режимами ADR-0047. Карточка показывает «SD эмулятора карты памяти»: загрузочные каналы (имена из `BootCard.ini`), `settings.ini` (режим, `Autoboot`, `CardSize`), число карт.
   - Отказы с понятной причиной:
     - установка загрузчика в корень и куда угодно на этой SD;
     - форматирование;
     - любая запись в служебные папки.
   - «Создать папки OPL» — только для профиля с MMCE.
   - Доктор: MBR и раздел 1 для 1.4.0; FAT32/exFAT; ничего о фрагментации.
   - Тесты: синтетическая раскладка на `MemFs` и в `make_library`, реальные данные — копия заводской SD (`#[ignore]`, `YAOPLM_TESTDATA`).
3. **PR 2 — чтение файловой системы карты PS2 (`yaoplm-formats`).**
   - Суперблок: IFC с кластера 8 или 16, `alloc_offset`, резервные блоки берутся из суперблока, не угадываются. Затем FAT, каталоги, файлы, заголовки `icon.sys` (Shift-JIS).
   - PS1: 15 кадров каталога; FreePSXBoot не «чинить».
   - Что лежит в загрузочной карте: FreeMcBoot/PS2BBL по `B?EXEC-SYSTEM` и `icon.sys`, образы SD Builder по SHA-256, версии OPL внутри. Предупреждение, если имя канала не совпадает с содержимым — на карте владельца так у каналов 3–6.
   - Сверка с mymcplusplus, как в `vmc_oracles.rs`; fuzz-цель.
4. **PR 3 — эмулятор по USB.**
   - Поиск порта по VID/PID и проверка ответом на `help` (`version`, если есть).
   - Команды переключения карты, канала, игры, режима, варианта: через план или подтверждение — это меняет, что видит консоль.
   - `reset bl` — не отправлять.
   - Порт открывать на одну команду и сразу закрывать.
   - Крейт: `serialport` 4.10.1 (MPL-2.0, совместима с GPL-3; синхронный; 2026-09-08). На Linux — без `libudev` (`default-features = false`), перечисление через sysfs. Проверить CI на трёх ОС.
   - Ядро без tokio (ADR-0003). Тесты на подменном порте по стенограммам.
   - Интерфейс: карточка «Эмулятор подключён по USB» с версией (если её даёт `version`) и кнопками каналов.
5. **PR 4 — библиотека на SD для загрузчиков с MMCE.**
   - Запись в каталог: форк `ps2-mmce/Open-PS2-Loader`, ветка `mmce_support`, семейство `mmce`.
   - Игры в `CD/`/`DVD/` в корне или под `mmce_prefix`; без правила фрагментов; `ul` из нескольких частей — предупреждать или отказывать (research/07 §2.7).
   - Подсказка: игры видит только сборка с MMCE, и в ней нужно включить режим MMCE. В заводском `conf_opl.cfg` нет ключей `mmce_*`, поэтому MMCE выключен (research/19 §4).
6. **PR 5 — OPL внутри загрузочной карты (LDR-5).**
   - Запись файловой системы карты: выделение кластеров, FAT, записи каталога, время. Можно портировать mymcplusplus (GPL-3) с указанием авторства; код OPL и ps2sdk (AFL) не копировать (ADR-0002).
   - Операция плана «записать файл внутри образа карты» с резервной копией всего `.mcd`.
   - Обновление `APPS/*.ELF` и правка `OPL/conf_opl.cfg`, в том числе `mmce_mode`.
   - После записи — проверка mymcplusplus `check`.
7. **PR 6 — сейвы (VMC-2).**
   - Список сейвов на картах PS2 и PS1.
   - Экспорт и импорт `.psu`, `.max`, `.cbs` (PS1 — `.mcs`, `.psv`).
   - Копирование между картами, карты по ID игры (`MemoryCards/PS2/<ID>/`, ID вида `SLUS-20062`).
   - Тот же код читает `VMC/*.bin` OPL.
   - Источники: mymcplusplus (`ps2save.py`, GPL-3); список форматов — из GDX-X `sd2psx-save-converter`. У GDX-X нет лицензии, поэтому только идеи, без кода. Группы карт для нескольких игр — `Game2Folder.ini` и `sync-on-luma/SD2PSX-VMC-Groups`.
8. **PR 7 — управление картами и новая SD (DEV-4).**
   - Правка имён каналов, `CardX.ini`, `Game2Folder.ini`, `settings.ini` (LF, пустая последняя строка), `CardSize`.
   - Новая загрузочная карта из образов SD Builder: загрузка по запросу, в программу не вшиваются (ADR-0007). Сначала проверить лицензии FMCB и PS2BBL.
   - Мастер «новая SD для эмулятора» и восстановление из копии.

## Решить по ходу (в ADR-0048, вопросы — владельцу одним списком)

- Как связать два подключения одного устройства. По USB серийный номер тома не виден; с прошивкой из `develop` YAOPLM мог бы найти свою метку через `ls`. Простейший вариант — две отдельные карточки.
- Нужна ли подтверждённая операция для переключения канала и карты по USB или достаточно кнопки.
- Веха: эта работа — продолжение M5 до тега v0.2.0 или M6 (в ROADMAP M6 есть «игры на SD эмулятора карты памяти» и форки с MMCE). Отметить в ROADMAP.
- Один модуль файловой системы карты для `VMC/*.bin` OPL и `.mcd` эмулятора (формат один).
- MemCard PRO 2 (закрытая прошивка, `PS2/<ID>/<ID>-<ch>.mc2`): поддерживать признаки и защиту сразу, остальное — когда будет устройство.

## Приложение: `help` на sd2psXtd 1.4.0 (устройство владельца, 2026-10-26)

```text
help
Serial Input Commands:
  help                                - Show this help
  reset bl                            - Reset to bootloader
  reset dev                           - Reset device
  channel up                          - Channel up
  channel down                        - Channel down
  set channel <idx>                   - Set channel index
  card up                             - Card up
  card down                           - Card down
  set card <idx> [channel <idx>]      - Set card with optional channel
  set game <id> [channel <idx>]       - Set game with optional channel
  set mode <mode>                     - Set mode: ps1, ps2
  set variant <variant>               - Set PS2 variant: retail, proto, conquest, arcade
>
```
